# 登頂之路：夜鋒 V1.3.6

V1.0 將高中生活與業餘電競世界正式接入既有 V0.9 架構。

新增：
- 每週動態電競新聞與世界事件。
- 全服菁英榜：路人王、實況主、青訓、職業選手會共同競爭排名。
- 好感階段：陌生、認識、朋友、親近、曖昧、非常親密。
- 新朋友與校園人物：俊凱、小宇、學妹陳語彤、學姊沈若晴、舊識許安然。
- 朋友五排，可透過朋友圈認識新人物。
- 緋聞基礎系統：高好感人物可能被同學議論，影響心情與未來聲譽架構。
- 金錢消費：飲料、聚餐、電競滑鼠、鍵盤、耳機、小禮物。
- 段考週與段考準備；讀書會累積準備度，成績影響家庭支持與心情。
- 業餘賽事：網咖週末盃、校際電競盃、城市青年盃，包含報名費、鎖定行程、名次、獎金、職業關注與新聞。
- 保留 V0.9 的 Rank 詳細結算、角色熟練度、手機訊息、約定、正式比賽日鎖定、外出與奇遇。

年齡規則：
- 主角未滿18歲時，不會出現成人親密事件。
- 成年後的親密關係架構預留為非露骨、淡出式事件，重點只放在時間、睡眠、心情、關係與競技狀態後果。

存檔：
- V1.0 使用 yefeng_v10_save。
- 會嘗試遷移 V0.9 / V0.8 / V0.7 / V0.6.1 / V0.6 本機存檔。
