# 登頂之路：夜鋒 V0.9

## V0.9 核心重構
- 手機訊息改為統一互動事件格式；需要回覆的訊息一定有選項。
- 新訊息動態產生後仍可點擊。
- 阿哲雙排 → 後續邀請組高中盃 → 回覆 → 報名 → 行程 → 正式比賽，完整串接。
- 正式比賽日為「鎖定行程」：當天首頁只允許前往比賽，不能 Rank、訓練、直播、社交、打工或逛街。
- 答應的普通約定會直接寫入指定時段，不能無故跳過。

## Rank / 訓練回饋恢復
- Rank 結算顯示：角色、KDA、LP前後、補刀、傷害、對線評級、團戰評級。
- Rank 會增加實際使用角色的熟練度。
- 訓練顯示「訓練前 → 訓練後」與精確增加值。
- 可選基礎能力、復盤研究、角色專項訓練。

## 角色熟練度
- 新增原創角色：璃月、影刃、星火、蒼嵐、凌風。
- 熟練度 0–100。
- 顯示使用場次、勝場、勝率。
- Rank 與專項訓練都會增加熟練度。

## 生活 / 社交 / 奇遇
- 社交會依已認識人物動態增加選項。
- 外出地點：商場、電競館、咖啡廳、便利商店、書店。
- 電競館可認識新人物「子辰」，事件有多個選擇與後續訊息。
- 商場可偶遇林雨晴並產生不同互動結果。
- 普通生活也可能沒有重大奇遇，避免每次出門都有主角事件。
- 放學奇遇也會提供實際選擇，不再只有通知文字。
