## 上傳 GitHub
把這個資料夾內的所有檔案直接上傳到 repository 根目錄。

## 最快公開方式：GitHub Pages
1. 進入 repository
2. Settings
3. Pages
4. Build and deployment → Source 選 Deploy from a branch
5. Branch 選 main，資料夾選 / (root)
6. Save
7. 等待 GitHub 產生網址
